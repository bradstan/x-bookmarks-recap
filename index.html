最简单：把这段话发给你的 AI

Claude Code、Codex、Cursor 这类能在电脑上运行命令的 AI 都可以。它会帮你导出收藏，跑完自动在浏览器里打开报告。

帮我生成我的 X 收藏夹年度报告。请在终端运行：

npx github:bradstan/x-bookmarks-recap

说明：它会读取我电脑上 Chrome 里 X 的登录状态，导出全部收藏并逐篇读取长文，可能要 5–10 分钟，请耐心等它跑完，不要中途停止；跑完会自动在浏览器里打开报告。如果提示没有 Node.js 或版本低于 22，请先帮我安装 Node.js 22 以上再运行。如果读取收藏失败，提醒我先用 Chrome 登录 x.com。

自己动手也只要一行

在已用 Chrome 登录 X 的电脑上，打开终端运行（需要 Node.js 22 以上）：

npx github:bradstan/x-bookmarks-recap

跑完会自动在浏览器打开报告，同时在当前目录留下一份 wrapped.json。长文要逐篇读取，几百篇大约 5–10 分钟；赶时间可以加 --no-articles。用 Firefox 的话加上 --firefox-profile default-release。

已经有 wrapped.json？

🔒 全部计算在你的浏览器里完成，数据不会上传到任何服务器。这个页面没有后端，代码全部开源。
